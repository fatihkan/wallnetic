# Wallnetic 1.6.0 — validation checklist

The manual checks for 1.6.0 (#343 B5). Run every check once, on the release
candidate. Fix failures, then re-check only what changed.

Most of 1.6 was built and looked at on one Mac: an Apple silicon Mac mini on
macOS 27 with external 1x displays and no battery. The checks below are the
ones that Mac could not do, plus a smoke test of everything on the oldest
system and on Intel. A check that needs a missing machine is reported as
untested, never as passed.

## Before the session

**Release candidate.** A Release build of the version to submit, not a Debug
build: sandbox, App Group and hardened runtime on, app and widget with the
same version and build. The Intel and macOS 13 checks use the CI-built DMGs.

**Machines.** Record which took part.

| Machine | Checks |
| --- | --- |
| MacBook with a notch, macOS 26 or 27 | Every check; the only machine for the **I** checks |
| Any Mac on macOS 13 | **S**, **G02**, **L06** |
| Intel Mac | **S**, **I07** |
| A Mac with two displays | **S06**, **P04**, **I08** |

## S — Smoke test (every machine)

| ID | Check |
| --- | --- |
| S01 | The app starts, the welcome tour runs through its four steps, and the sample wallpaper plays. |
| S02 | Home shows each display's wallpaper and status. Recently Used and Recently Added fill in after two wallpapers are applied. |
| S03 | Library: the filter chips, the colour filter, sorting and search work. A wallpaper's context menu shows Preview…, Scaling, Rename and the favorite action. |
| S04 | The menu bar menu lists each display's status, the playback profile, Pause, Calm Mode, Next, Open Wallnetic, Settings…, Rate and Quit. Each one works. |
| S05 | Settings: every page opens. The gear button, the menu bar's Settings… and ⌘, all bring the same single window forward, also after it was minimized. A scrolled page does not show through the title. |
| S06 | Calm Mode, the Desktop Clock, and switching wallpapers on two displays (the #343 acceptance list). |
| S07 | Both renderers play: Settings > Playback > Use Metal Renderer on and off. |

## G — Interface (#343)

| ID | Check |
| --- | --- |
| G01 | macOS 26 or later: the now-playing bar, sheets and overlays use Liquid Glass, in the light and in the dark appearance. |
| G02 | macOS 13 to 25: the same surfaces keep the earlier look, and the title bars are intact (#237 was reported on macOS 26.6.2: check that version if one is at hand). |
| G03 | No neon or glow is left on navigation, cards or Home. |

## P — Preview, scaling and playback rules (#348, #349, #350)

| ID | Check |
| --- | --- |
| P01 | Preview… plays the wallpaper with its trim, scaling, effects and clock, and the desktop does not change until Apply. Run it once with the **AVPlayer** renderer: only Metal was seen. |
| P02 | Fit with Blurred Backdrop on a portrait video and on an ultrawide video: the whole frame shows, the backdrop is blurred, and switching back to Fill is immediate. |
| P03 | **Pause on low battery**, on a MacBook: unplug below the chosen level, see the status name the rule, plug in and see playback continue. Not seen at all so far: the development Mac has no battery. |
| P04 | **Pause while chosen apps are running**: add an app, start it, quit it. **Play only on the display in use**, with two displays. |
| P05 | A rule never undoes a manual Pause: pause by hand, trigger and end a rule, and the wallpaper stays paused. |

## L — Languages (#351)

Run in each language that is to ship: German, French, Japanese, Simplified
Chinese. Start the app in a language with
`open -n Wallnetic.app --args -AppleLanguages "(de)"`, or set the Mac's
language.

| ID | Check |
| --- | --- |
| L01 | **A native speaker has read the language**, with `docs/LOCALIZATION_GLOSSARY.md`. Without this the language does not ship. |
| L02 | Not looked at in any translation yet, so look for English leftovers and cut-off text: the menu bar menu, context menus, the preview, trim, optimize, wallpaper packs and import-from-link sheets, error messages, the Dynamic Island, the widget, the Photos permission prompt and the Shortcuts app. |
| L03 | The light appearance: Home, Library, Discover and each Settings page. Only the dark appearance was seen. |
| L04 | A new user's schedule: with no saved schedule, the four ranges carry translated names. |
| L05 | Counts: one and several files, minutes and displays read correctly ("1 Datei", "2 Dateien"). |
| L06 | macOS 13: the app starts in the system's language and falls back to English for a language it does not have. |
| L07 | The Desktop Clock shows the weekday and month in the app's language. Seen in German only. |

## I — Dynamic Island (#352)

Turn it on in Settings > General > Dynamic Island.

| ID | Check |
| --- | --- |
| I01 | **On a MacBook the compact island reads as part of the notch**: no seam and no step, with a light and with a dark wallpaper behind the menu bar. Seen only with a simulated notch. |
| I02 | Hover opens it, leaving closes it after a moment, and it never flickers when the pointer rests on its edge. Not tried with a real pointer. |
| I03 | Each control: play or pause, next, Calm Mode, the playback profile, Open Wallnetic. A video file dropped on the island is imported. |
| I04 | It comes back after the app is quit and started again. |
| I05 | It steps aside for a full-screen app and returns afterwards. After changing the wallpaper with a hotkey or while typing, it stays closed. |
| I06 | Reduce Motion (the card fades, nothing stretches) and Increase Contrast (solid fill, outline, no glow), switched on in System Settings. |
| I07 | Intel Mac and a display without a notch: the floating pill below the menu bar, with the same opening motion. |
| I08 | A MacBook with an external display: the notch variant on one, the pill on the other, opening together. |
| I09 | The menu bar items beside the notch stay clickable up to the island's ears. |

## Recording

For each ID record: pass, fail or untested, the machine and macOS version, and
