## What's New — English

This update improves wallpaper playback and the everyday library experience.

- More reliable wallpaper loading, looping and switching, with improved video proportions.
- Window controls and first-launch setup improvements for macOS Tahoe.
- Fixes for gallery previews, library imports, search and Settings.
- Better handling of pause, wake and interrupted video loads.
- Stability improvements when opening links and importing downloaded wallpapers.

## Review notes

existing application permissions are unchanged. Video playback remains
independent of the main window. The release contains the native window-control
and onboarding changes from #242 and the playback/library fixes since 1.4.1.

The intermittent invisible-control report in #237 was not reproduced exactly
in the local visual host; the issue remains open for reporter confirmation.
