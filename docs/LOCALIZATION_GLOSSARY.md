# Translation rules and glossary (#351)

For anyone translating or reviewing Wallnetic's interface. How the files and
tools work is in [LOCALIZATION.md](LOCALIZATION.md).

## Rules

1. **Placeholders stay as they are:** `%@`, `%lld`, `%.2f`, `%%` and line
   breaks. Keep every one, the same number of times. When a sentence needs
   them in another order, number them: `%1$@`, `%2$lld`.
2. **Keep in English:** Wallnetic, Pexels, Pixabay, Wallhaven, Steam Workshop,
   Wallpaper Engine, MyLiveWallpapers, DesktopHut, MoeWalls, MotionBGs, Metal,
   AVPlayer, H.264, HEVC, HDR, MP4, MOV, GIF, WebM, ffmpeg, GitHub, App Store,
   Mission Control, fps, 4K, HD.
3. **Use the words macOS uses** in the language for system things: Settings,
   menu bar, Dock, Finder, Low Power Mode, screen saver, Lock Screen, Spaces,
   Shortcuts, display.
4. **Follow the interface style of macOS in the language:** short labels, no
   English title case. A menu item that ends with `…` keeps it.
5. **Length:** a label, button or menu item should be no longer than about
   1.3 times the English. The Settings sidebar and the filter chips are the
   tightest places.
6. **Tone:** plain and direct. Say what happens. German uses `du`, French
   `vous`, Japanese the です/ます form for sentences and plain forms for
   labels, Chinese `你`.
7. **One term, one translation.** Follow the table below.
